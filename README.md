## 🚀 三步上手（30 秒）

1. **打开网页**（手机浏览器直接开，无需下载）
2. **拍一张单词表照片**（或从相册选），核对识别出的清单
3. **点"开始听写"** —— 剩下的交给 App 和娃

## 📱 详细使用说明

### 准备听写清单
- 点"拍照识别"直接拍，或点"从相册选取"选已有的照片
- 识别完成后会列出"英文 = 中文"清单，**务必花 10 秒核对一遍**，错的点一下就能改
- 清单行首可标或，识别不准时手动修正

### 开始听写
- 选择模式：**随机顺序**（推荐，防止娃背顺序）或**按清单顺序**
- 点"开始听写"，App 会朗读第一题的中文意思
- 娃写完后：
- **语音接力**：直接说"好了"，App 回应"好的，下一个听写"并报下一题
- **手动模式**：点"好了，下一题"大按钮（iPhone 上语音识别可能不稳定，大按钮永远可靠）

### 听写结束
- 全部报完自动播报"听写完成"🎉
- 可点"显示答案"逐题核对，或"再来一轮"巩固

## ❓ 常见问题

**Q：iPhone 上说"好了"没反应？**
A：iOS 浏览器对网页语音识别支持有限，这是系统限制。用页面上的大按钮一样顺手，不影响使用。

**Q：识别出来的中文意思不对？**
A：拍照时尽量端正、光线充足；识别后清单可逐条修改，改完再开始。

**Q：需要联网吗？**
A：语音播报和识别需要网络；页面本身打开一次后可正常使用。

**Q：数据会上传吗？**
A：不会。所有识别和播报都在你手机浏览器里完成，不注册、不登录。
